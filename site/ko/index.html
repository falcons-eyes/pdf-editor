PDF에 서명과 도장, 봉인까지.

받은 PDF에 서명과 도장을 넣고 새 파일로 저장해요. Mac과 Windows, Android에서 무료로 쓸 수 있고, 계정도 인터넷 연결도 필요 없어서 파일이 내 기기 밖으로 나가지 않아요.

세 단계면 끝나요

  1. PDF 열기

    새 PDF 열기를 누르거나 파일을 창에 끌어다 놓아요.

  2. 서명과 도장 놓기

    목록에서 고른 서명이나 도장을 원하는 자리로 끌어 놓고 크기와 각도를 맞춰요.

  3. 새 파일로 저장

    원본은 그대로 두고 계약서_서명.pdf 같은 새 PDF를 만들어요.

이럴 때 써요

  • 집주인이 월세 계약서를 메일로 보냈을 때

    출력하지 않고 서명과 도장을 넣어서 바로 돌려보내요.

  • 알바생 근로계약서를 받아야 할 때

    매장 태블릿에서 바로 서명받고 사장님 도장까지 찍어요.

  • 견적서를 오늘 안에 보내야 할 때

    회사 직인 사진의 흰 배경을 지우고 깔끔하게 찍어요.

  • 아이 현장체험학습 신청서를 낼 때

    사진 찍어 보내지 말고 보호자 서명을 깔끔하게 넣어요.

  • 지출결의서에 결재 도장을 찍을 때

    여러 쪽의 같은 자리에 도장을 한 번에 찍어요.

  • 용역 계약서를 주고받을 때

    서명하고 봉인해 두면 나중에 고쳐진 곳이 있는지 바로 알 수 있어요.

봉인하면 고친 티가 나요

저장할 때 봉인해서 저장을 켜면 완성된 파일 전체에 디지털 서명을 넣어요. 그 뒤로 누가 한 글자라도 고치면 봉인 확인에서 바로 드러나요.

봉인이 고치는 것 자체를 막지는 못해요. 고친 걸 숨길 수 없게 할 뿐이에요.

법령상 인정된 전자서명은 아니에요. 다른 앱에서 다시 저장하면 봉인이 깨지니 받은 파일은 그대로 두세요. 확인하는 방법과 봉인 키 백업은 지원 페이지에 정리해 두었어요.

Mac과 Windows용 파일은 GitHub에서 받아요. macOS 13 이상, 64비트 Windows 10과 11에서 동작해요.

  • Mac (Apple Silicon)…-arm64.dmg
  • Mac (Intel)…-x64.dmg
  • Windows 설치형…-setup-x64.exe
  • Windows 설치 없이 실행…-portable-x64.exe
GitHub에서 받기

Apple과 Microsoft의 유료 인증서로 서명하지 않은 파일이라 처음 열 때 한 번 경고가 떠요. 처음 여는 방법을 참고하세요.

앱은 회사를 포함해 누구나 무료로 쓸 수 있어요. 소스 코드는 비상업적 용도로 공개하고, 고친 버전이나 코드의 상업적 이용은 support@falconoon.com으로 허락을 받아야 해요. 자세한 조건은 라이선스와 추가 허용에 있어요.
